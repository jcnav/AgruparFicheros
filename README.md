# Agrupar Ficheros

Es una aplicación muy básica que agrupa los ficheros si coinciden en un número determinado de caracteres del nombre. 

Ej. Tenemos dcim001.jpg dcim001_1.jpg pepe.jpg, ...


La app en funcion de la configuracion creara un directorio llamado dcim001 y movera dcim001.jpg dcim001_1.jpg a ese subdirectorio.

## Opciones
Se pueden elegir:
* El número mínimo de ficheros con el patrón para que se produzca la agrupación. 
* El número mínimo de caracteres que se buscará para agrupar (por ejemplo 4, crearía dcim) y se puede activar "recursividad".
* La recursividad es simplemente establecer un número mínimo de caracteres por el que comenzar la agrupación e ir descendiendo en ese número de caracteres para continuar agrupando.
